# سفرینو (Safarino)

اپلیکیشن مدیریت و تقسیم هزینه‌های سفر گروهی — فارسی، RTL، بدون نیاز به نصب.

## اجرا

فایل `index.html` را در مرورگر باز کنید. برای فعال شدن حالت PWA و کار آفلاین،
پروژه را روی یک وب‌سرور (مثلاً GitHub Pages) قرار دهید.

## ساختار

| فایل | توضیح |
|---|---|
| `index.html` | کل برنامه (HTML + CSS + JS، بدون وابستگی خارجی) |
| `manifest.json` | تنظیمات PWA |
| `sw.js` | سرویس‌ورکر برای کار آفلاین |
| `icons/` | آیکن‌های برنامه |

## امکانات

- ثبت هزینه با تقسیم مساوی یا سفارشی
- محاسبه خودکار بدهی/طلب هر نفر و پیشنهاد کمترین تعداد تراکنش برای تسویه
- ثبت پرداخت‌های واقعی (تسویه‌ها روی مانده‌حساب اثر می‌گذارند)
- نمودار دسته‌بندی هزینه‌ها، گزارش آماری و خروجی PDF از طریق چاپ مرورگر
- خروجی/ورودی JSON برای پشتیبان‌گیری و انتقال بین دستگاه‌ها
- پنج تم، پشتیبانی کامل از ارقام فارسی، و قابلیت بازگردانی (Undo)

## نکته مهم

سفرینو داده‌ها را فقط در `localStorage` مرورگر نگه می‌دارد و سروری ندارد.
کد سفر تنها روی همان دستگاه کار می‌کند؛ برای انتقال سفر به دستگاه دیگر از
خروجی JSON استفاده کنید.
